# 优化实施记录

## 目标

在保持项目结构清晰、易于维护的前提下，提高判定可解释性、数据追溯、通信可靠性、异常恢复和GitHub可维护性。

## 已完成

- 圆度不再作为静默轮廓过滤条件，独立输出`CIRCULARITY_NG`。
- 新增长宽比上下限和`ASPECT_RATIO_NG`。
- 新增期望中心、允许偏移和`POSITION_NG`。
- 支持深色/亮色目标切换，并增加自适应阈值参数。
- 增加可选像素当量，将像素宽高和面积换算为毫米与平方毫米。
- 标定结果进入SQLite、历史列表和CSV，默认值0明确表示未标定。
- 配方增加名称和版本；检测记录增加产品、操作员及PLC周期号。
- 历史记录支持按结果、批次、产品型号和日期组合查询。
- 进入自动模式后锁定检测配置，退出后恢复编辑。
- PLC周期号缓存在同一应用生命周期内跨重连保留，避免断线重发导致重复检测。
- 增加推送前审计脚本，检查大文件、常见密钥格式、Git差异和Release测试。
- 历史总数、良率和NG分布改为严格使用当前筛选结果，避免全库统计误导。
- 增加用户确认式孤立NG图片清理，只删除超过7天且数据库未引用的托管PNG。
- 增加现场系统自检，检查数据目录、SQLite、OpenCV运行库和默认配方。
- 最终EXE增加`--self-test`模式；本地预推送与GitHub Actions直接验证发布目录依赖。
- 增加独占执行的1000次视觉处理资源增长测试，防止后续修改引入Mat释放回归。
- 提取`IPlcClient`通信抽象，为真实Modbus和厂商协议适配器预留替换点。
- 提取`ICameraFactory`，为海康、大华等工业相机SDK适配器预留创建入口。
- 增加JSONL操作审计，记录检测、配方、PLC周期和NG清理，日志失败不影响主业务。
- 配方保存增加变更检测、覆盖前备份和最近20版保留策略。
- 增加标签Release、Dependabot、Issue表单和GitHub配置本地校验。
- 新参数兼容旧JSON配方；默认值表示不启用新增限制。
- SQLite新增长宽比和中心偏移字段，启动时自动迁移旧数据库。
- CSV同步导出新增测量值。
- PLC客户端缓存最近1000个周期号，重复START只触发一次。
- 主窗口支持测试数据目录注入，避免测试污染用户数据。
- 增加全局异常日志。
- 增加GitHub Actions、贡献说明、安全说明和变更记录。
- 优化主窗口工具栏、输入控件尺寸和间距，并生成GitHub展示截图。
- WPF界面测试加载示例并执行检测后渲染PNG，校验截图尺寸和文件完整性。
- Release工作流在无还原发布前显式还原`win-x64`运行时资产，并由本地配置检查防止回归。
