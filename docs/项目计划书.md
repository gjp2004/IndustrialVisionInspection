# 工业零件视觉检测上位机项目计划书

## 1. 项目目标

开发一套 Windows 工业视觉检测上位机，实现“图像输入—视觉分析—OK/NG 判定—结果保存—PLC 模拟通信”的完整闭环，用于工程实践和机器视觉应用工程师、C# 上位机岗位作品展示。

## 2. 检测对象

第一版选择白色背景上的深色圆形或近圆形零件，例如垫片、硬币和瓶盖。检测数量、面积、中心、宽高和圆度。

## 3. 技术栈

| 类别 | 技术 |
|---|---|
| 平台 | .NET 8、Windows x64 |
| 界面 | WPF、XAML |
| 架构 | 简化 MVVM |
| 视觉 | OpenCvSharp 4 |
| 数据 | SQLite、JSON、CSV |
| 通信 | TCP 文本协议；Modbus TCP 为扩展项 |
| 测试 | xUnit |

## 4. 核心功能

1. 本地图片与 USB 摄像头输入。
2. ROI、灰度、滤波、阈值、形态学和轮廓分析。
3. 数量、面积、中心、宽高和圆度测量。
4. 按配方参数输出具体 OK/NG 原因。
5. 手动检测和 PLC 自动触发。
6. SQLite 检测历史、NG 图片和 CSV 导出。
7. JSON 配方管理。
8. 心跳、超时、断线重连和运行日志。

## 5. 八周进度

| 周次 | 目标 | 验收结果 |
|---|---|---|
| 1 | 项目骨架和界面 | 程序可启动，界面不卡顿 |

| 3 | 视觉算法 | 能检测简单零件并绘制结果 |
| 4 | 判定与配方 | 参数可保存，NG 原因明确 |
| 5 | SQLite 追溯 | 可查询历史、保存 NG 图片 |
| 6 | TCP/PLC 模拟 | 能远程触发并返回结果 |
| 7 | 测试与重构 | 至少 15 个有效测试 |
| 8 | 发布和作品集 | README、Release、演示视频齐全 |

## 6. 验收标准

- 可检测简单圆形零件并输出可解释结果。
- 可保存和查询检测历史。
- 模拟 PLC 可以触发检测并取得结果。
- 连续运行 30 分钟无崩溃和明显内存增长。
- 至少包含 15 个自动化测试。
- README 明确区分模拟验证与真实产线能力。
