# 相机适配接口说明

## 当前架构

```text
MainViewModel
    ↓ ICameraFactory
DefaultCameraFactory
    ├─ SimulatedCamera
    └─ UsbCamera

CameraAcquisitionService
    ↓ ICamera
具体相机实现
```

主业务不再直接`new`具体相机。接入工业相机时，可以扩展工厂或注入新的`ICameraFactory`。

## ICamera契约

```csharp
public interface ICamera : IDisposable
{
    bool IsOpen { get; }
    bool Open();
    Mat Capture();
    void Close();
}
```

实现类必须保证：

- `Open`失败时返回`false`或抛出具有设备信息的异常。
- `Capture`返回调用者拥有的有效`Mat`，调用者可以安全释放。
- 未打开、掉线和取帧超时时给出明确异常。
- `Close`可以重复调用。
- `Dispose`释放相机句柄、缓冲区、回调和厂商SDK资源。
- 不从SDK回调线程直接修改WPF界面。

## ICameraFactory契约

```csharp
public interface ICameraFactory
{
    IReadOnlyList<string> Sources { get; }
    ICamera Create(string source, int deviceIndex);
}
```

工业相机插件可以实现自己的工厂，并在创建`MainViewModel`时注入。

## 厂商SDK适配建议

建议新增：

```text
Camera/HikvisionCamera.cs
Camera/DahuaCamera.cs
Camera/IndustrialCameraFactory.cs
```

适配时需要处理：

- 枚举设备和稳定的设备标识符。
- 连续采集与软触发/硬触发。
- 曝光、增益、帧率和像素格式。
- Mono8、Bayer等格式转换为OpenCV Mat。
- SDK缓冲区生命周期和深拷贝。
- 取帧超时、设备拔出和自动重连。
- 触发序号与PLC周期号对应。

## 实物验收要求

- 冷启动和重复打开/关闭各100次。
- 连续采集2小时无崩溃、无持续内存增长。
- USB拔插或网线断开后能识别故障并恢复。
- 曝光和增益参数重启后符合预期。
- 硬触发不丢帧、不重复帧。
- 图像序号与PLC周期号可追溯。
- 在实际光源、镜头和工作距离下验证检测结果。

未完成上述实物验证前，不应声称兼容具体工业相机型号。
